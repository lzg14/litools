2. **JSON**（1875 错误位置、2322 JSONPath 匹配数、2333 b64 编码失败）
3. **URL 解析**（2367-2375）：协议/主机/端口/路径/查询/哈希/来源/参数
4. **搜索模块**（2573/2579/2639/2687）：匹配计数、仅显示前N、文本过大跳过高亮
5. **正则解释**（2953-2984）：字符类映射、分组断言描述、反向引用
6. **正则速查**（3070-3086）：模板名（手机号/日期/提取数字 等）
7. **Cron 解析**（3132-3134）：每小时/每工作日 等描述
